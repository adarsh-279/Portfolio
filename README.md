# 🚀 Portfolio Website

A modern, responsive, and performance-focused personal portfolio built with **React**, **Tailwind CSS**, and **Framer Motion**.  
This website showcases my skills, projects, education, and experience with a clean UI, smooth animations, and dark mode support.

🌐 **Live Site:** https://adarshshaw.vercel.app/

---

## ✨ Features

- ⚡ **Fast & Responsive UI** — Optimized for all screen sizes
- 🌗 **Dark / Light Mode** — System-aware theme support
- 🎨 **Modern Design** — Minimal, clean, and recruiter-friendly
- 🎞 **Smooth Animations** — Powered by Motion
- 🧩 **Component-Based Architecture** — Clean and scalable code
- 🖼 **Optimized Assets** — Uses `.webp` images for better performance
- 🔗 **Social & Resume Links** — One-click access to GitHub, LinkedIn, X and Resume

---

## 🛠 Tech Stack

### Frontend

- **React.js** – Build interactive UI components  
- **Tailwind CSS** – Fast, responsive styling  
- **Motion** – Smooth, subtle animations and transitions  
- **React Router DOM** – Client-side page navigation  
- **Lenis** – Smooth, natural scrolling  

### Tooling & Deployment

- **Vite** – Fast development and builds  
- **Vercel** – Easy hosting and deployment  
- **Git & GitHub** – Version control and collaboration  

---

## 🧠 Design Philosophy

- Focus on clarity over clutter
- Subtle animations to enhance UX, not distract
- Recruiter-first layout and content flow

---

## 📈 Performance & Optimization

- Lazy-loaded non-critical assets
- Optimized SVGs and images
- Minimal bundle size using Vite
- Clean Tailwind utility usage
